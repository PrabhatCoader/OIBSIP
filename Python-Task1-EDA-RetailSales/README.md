# Task 1 - Retail Sales EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data using Python.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning and inspection
- Descriptive statistics
- Monthly and quarterly sales analysis
- Customer age and gender analysis
- Top products and category revenue analysis
- Correlation analysis
- Business insights and recommendations

## Project File
The main analysis is available in:
`Task_1_retail_sales_EDA.ipynb`
